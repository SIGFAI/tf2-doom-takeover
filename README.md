# Doom Takeover

**Team Fortress 2** × Doom · visual · idea by the team

Bring Doom into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned every TF2 fighter into a 3D Doom marine, imp or cacodemon, and the kill screen goes full RIP AND TEAR with flying skulls.

## Install

Copy the mod folder into Team Fortress 2's tf/custom folder, start a local game on any map with bots, and everyone turns into Doom monsters and marines.
